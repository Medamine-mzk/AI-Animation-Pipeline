POURQUOI CE SITE N'EST QU'UNE PAGE D'INFORMATION WHY THIS IS ONLY AN INFORMATION PAGE

L'hébergement gratuit ne peut pas exécuter ce projet

The free tier cannot run this project

Ce n'est pas une limite de l'application mais une question de taille. Les modèles de reconnaissance vocale pèsent à eux seuls 879 Mo, et une transcription complète atteint un pic d'environ 1,76 Go en mémoire.

This is not a limitation of the application but one of size. The speech recognition models alone weigh 879 MB, and a full transcription peaks at roughly 1.76 GB of memory.

Le palier le moins cher qui pourrait fonctionner laisse presque aucune marge. La voie prise en charge est donc Docker sur votre propre machine, où la mémoire n'est pas plafonnée par un quota d'hébergement.

The cheapest plan that might work leaves almost no headroom. The supported path is therefore Docker on your own machine, where memory is not capped by a hosting quota.
